NOTE: Make sure your have love2D installed already.
Run Retro1984 by right mouse on Retro1984.zip will allow you to create yourself as an Author, this way you will find yourself in the above path.

If you didn't clone the code and just downloaded the zip, notice that you will need to change the file structure inside the (zip).love file to look like below. Because it's nested our /root away out of reach so cut and paste folders and files up a directory.
/fonts
/source
conf.lua
main.lua
RVnumbers.lua

Unpack author along side your other authors located inside
$USER/.local/share/love/retro84/Authors/
